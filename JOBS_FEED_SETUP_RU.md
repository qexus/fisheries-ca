# Fisheries: подключение проверенных вакансий

**Статус:** интерфейс, модель данных, фильтрация и тесты работают. Автоматическая лента **не подключена** ни в Норвегии, ни в Канаде: нет согласованного машиночитаемого источника.

## Что уже работает

- В разделе «Объявления» показываются отдельный блок проверки вакансий и ссылки на официальный актуальный поиск.
- `scripts/refresh_jobs.py` строит `public/generated/jobs.json` из доверенной авторизованной JSON-выгрузки.
- Неактивные, просроченные, неподтверждённые больше 36 часов, не-HTTPS и неполные записи исключаются.
- На публичной странице не публикуются email/телефоны физических лиц и не копируется сырой HTML.
- При отсутствии интеграции публикуется `status: not_connected`, а старые объявления остаются явно архивными.
- Регрессионные тесты проверяют дедупликацию, статус, срок и URL.

## Норвегия: официальный NAV Job Vacancy Feed

Источник: https://navikt.github.io/pam-stilling-feed/

Доступен бесплатно, но **требует подписанного JWT-токена**. Публичный токен предназначен для экспериментов и может заменяться. Для устойчивого подключения NAV предлагает зарегистрироваться в качестве потребителя: напиши на **nav.team.arbeidsplassen@nav.no**, подтвердив согласие с условиями и указав название проекта/организации, контактное лицо, контактный email и телефон.

Условия: https://arbeidsplassen.nav.no/vilkar-api

NAV требует незамедлительно отражать изменения и удалять неактивные вакансии, соблюдать правила обработки контактных данных и предоставлять прямую ссылку на настоящий способ подачи заявления. Поэтому **еженедельный парсинг веб-страницы без разрешения не подходит**; даже наличие токена само по себе не доказывает готовность всего процесса. До настройки надёжной синхронизации показываем пользователю прямой официальный поиск: https://arbeidsplassen.nav.no/stillinger?q=fisk

## Канада: Job Bank

Публичный поиск: https://www.jobbank.gc.ca/jobsearch/jobsearch?searchstring=seafood%20processing&sort=D

Job Bank предлагает XML feed для **приёма объявлений от других сайтов**, а не общедоступный API для свободного массового скачивания всех объявлений: https://www.jobbank.gc.ca/network

До появления разрешённого API или согласованной партнёрской выгрузки не имитируем поток свежих вакансий. Ссылки на карьеры конкретных компаний остаются отдельным каталогом и не являются подтверждением активного набора.

## Пример разрешённого входного формата

```json
{
  "distribution_authorized": true,
  "source": "Organization with explicit re-publication permission",
  "jobs": [
    {
      "id": "provider-100",
      "title": "Production operator",
      "employer": "Example Employer",
      "location": "Québec",
      "url": "https://example.org/jobs/100",
      "source": "Authorized partner",
      "status": "ACTIVE",
      "verified_at": "2026-11-16T23:00:00Z",
      "expires_at": "2026-11-25T23:00:00Z"
    }
  ]
}
```

Файл должен поступать из официального или договорного источника и отражать изменения/удаления согласно его условиям. Значение `distribution_authorized` нельзя выставлять без реального разрешения.

Для тестирования локально:

```bash
python scripts/refresh_jobs.py --input authorized.json --out public/generated/jobs.json
python -m unittest discover -s tests -v
```

**Не загружай приватные JWT-токены, пароль или полные персональные данные работодателей в публичный GitHub.** Подключение рабочих ключей следует делать через секреты GitHub Actions и с учётом соглашения провайдера. Текущие workflow не используют таких секретов и не заявляют, что вакансии обновляются автоматически.
