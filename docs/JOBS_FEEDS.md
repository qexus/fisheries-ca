# Подключение актуальных вакансий к qexus Fisheries

**Статус:** формат импорта готов, но поставщик подтверждённых вакансий ещё **не подключён**. Не называй архивные объявления «живыми».

## Как работает импорт

В обоих репозиториях `scripts/refresh_jobs.py` автоматически выполняется при публикации сайта (push, ручной запуск и еженедельный запуск). По умолчанию он создаёт `public/generated/jobs.json` со статусом `not_connected` и пустым массивом `verified_live`.

Когда подключён **источник, разрешающий републикацию**, добавь в **Settings → Secrets and variables → Actions → New repository secret**:
- `FISHERIES_JOBS_FEED_URL` — адрес HTTPS с JSON-лентой, которую ты уполномочен использовать на публичном сайте.
- `FISHERIES_JOBS_FEED_TOKEN` — необязательный Bearer-токен доступа. Никогда не вставляй его в публичный JavaScript, HTML, коммиты или сообщения.

Запрос к URL выполняется только на стороне GitHub Actions. Сам сайт публикует **минимизированные данные**, без контактных лиц, их электронной почты, номеров телефона и описаний, которые могут содержать персональные данные.

## Формат разрешённого экспорта

Пример без настоящих вакансий:

```json
{
  "distribution_authorized": true,
  "source": "Licensed or expressly redistributable provider",
  "jobs": [
    {
      "id": "fictional-123",
      "status": "ACTIVE",
      "title": "Seafood processing operator",
      "employer": "Example company",
      "location": "Example location",
      "url": "https://example.org/jobs/123",
      "verified_at": "2026-11-16T18:00:00Z",
      "expires_at": "2026-11-20T23:59:00Z"
    }
  ]
}
```

`distribution_authorized: true` означает документально подтверждённое разрешение источника на публикацию, а **не обход его условий**. `verified_at` должен выставлять поставщик после подтверждения активности в первоисточнике. Записи с истёкшим сроком, непризнанным статусом, небезопасным URL или проверкой более 36 часов назад не публикуются.

**Важно:** GitHub Actions по расписанию сейчас обновляет данные раз в неделю. Поэтому для действительно живой ленты нужен более частый обновляющий процесс или источник, гарантирующий мгновенное удаление закрытых объявлений, и периодические сборки. Публикация только по понедельникам **не удовлетворяет** правилам NAV о своевременном удалении закрытых вакансий. Не подключай NAV напрямую к этому графику, даже если токен получен.

## Норвегия: официальная NAV Job Vacancy Feed

Документация: https://navikt.github.io/pam-stilling-feed/
Условия: https://arbeidsplassen.nav.no/vilkar-api

API бесплатен, но требует JWT. Публичный токен предназначен только для экспериментов и меняется нерегулярно; для постоянного доступа нужно зарегистрировать потребителя. NAV требует, чтобы изменения и деактивации вакансий отражались быстро, и может скрывать контакты у закрытых объявлений. Исходный NAV event-feed **не совпадает** с упрощённым JSON-форматом выше: для него необходим отдельный преобразователь, корректное ведение состояния и обработка INACTIVE.

Контакт: nav.team.arbeidsplassen@nav.no. В запросе на персональный токен NAV просит название/идентификатор проекта, контактное лицо, email и телефон, а также письменное согласие с условиями использования. Эти данные следует сообщить NAV напрямую и не публиковать на GitHub.

## Канада: Job Bank

Официальные правила обмена вакансиями: https://www.jobbank.gc.ca/network

Доступ к **исходящей XML-выгрузке Job Bank** могут запросить существующие канадские job boards. В качестве условий указаны активный Business Number, действующий сайт вакансий для канадской аудитории, бесплатный доступ без регистрации и ссылки на первоисточник. Наличие собственного сайта на GitHub само по себе не гарантирует одобрения.

При отсутствии партнёрского доступа используй ссылки на поиск на официальном Job Bank. Старый список объявлений на сайте должен оставаться архивным.

## Защита данных и диагностика

- Источники с локальными/частными IP, незашифрованным HTTP и вшитыми URL-учётными данными отклоняются.
- Импорт ограничен 2 МБ; выдача ограничена 250 записями в файл, а на экране выводится до 50.
- Для новых закрытых вакансий требуется актуальная метка статуса и срок действия — без этого они исключаются.
- Если источник недоступен или неверно настроен, сайт не объявляет архивные вакансии действующими.
- Сборка автоматически тестирует правила импорта; публичный статус: https://qexus.github.io/status.html.

## Следующее техническое действие

Получить разрешение и схему реального поставщика данных. Затем написать преобразователь **под конкретный API**, проверить отзыв и обновление объявлений, настроить достаточно частые публикации и только после этого указывать полноценную автоматическую ленту.
