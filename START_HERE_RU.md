# qexus lab Fisheries — Canada 🇨🇦

**Это отдельная канадская версия нашего норвежского проекта.** Норвежский репозиторий `qexus/fisheries` не изменяется.

## Уже сделано

- Мобильный веб-интерфейс с поиском по провинциям, компаниям и вакансиям.
- Реестровая часть: 37 вручную отобранных записей CFIA плюс скрипт полной автоматической загрузки CFIA и реестров аквакультуры DFO BC.
- Вакансии: 18 объявлений Job Bank как датированные записи для повторной проверки.
- 10 уроков и 56 терминов, личный прогресс только в браузере.
- GitHub Actions: проверка Python, обновление JSON, публикация Pages.
- Импорт CSV и резервное копирование пользовательских отметок.

## Что пока не готово

- **Реальная выгрузка всей CFIA/DFO базы из GitHub Actions не тестировалась в этой среде.** GitHub получит доступ к источникам только после первого запуска workflow, тогда можно исправить несовпадения схем данных.
- Вакансии сами не обновляются; для них нужно отдельное согласованное решение, не выдающее устаревшие записи за актуальные.
- Проверенные HR email/телефоны и отдельная канадская база судовладельцев не собраны.
- Нет аккаунтов и облачной синхронизации: личные заметки сохраняются на устройстве.

## Размещение

Предлагаемое имя нового публичного репозитория: `fisheries-canada`. Сайт будет `https://qexus.github.io/fisheries-canada/` после успешной публикации. Можно передать мне доступ после создания репозитория, чтобы загрузить файлы и проверить запуск. В настройках Pages: **Source → GitHub Actions**.

Начни с учебника №1 или вкладки «Компании и фабрики», а затем переходи к Job Bank. **Ни одно резюме и письмо автоматически не отправляются.**
