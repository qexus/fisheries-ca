# qexus lab · Fisheries Canada 🇨🇦

Canada edition of [qexus lab Fisheries Norway](https://qexus.github.io/fisheries/).

**Public site (after Pages deployment):** https://qexus.github.io/fisheries-ca/

The project is an independent open-data research and self-study tool for Canadian seafood processing, aquaculture, fishing operations and employment resources. Establishment listings are not job offers, and Job Bank snapshots must be checked against the original posting.

**Status:** repository initialized. The prepared website, dataset and GitHub Actions workflow will be uploaded next. The separate Norwegian project is unchanged.

Project hub (planned): https://qexus.github.io/
